# Form Builder Project

This project consists of a frontend client (Next.js) and a backend server (Express.js).

## Prerequisites

- Node.js (v18 or higher)
- npm (v9 or higher)

## Setup

The project is divided into two parts: `client` and `backend`.

### 1. Backend

Navigate to the `backend` directory and install dependencies if you haven't already:

```bash
cd backend
npm install
```

To start the backend server:

```bash
npm run dev
```

The server will start on port 5000 (or the port specified in `.env`).

### 2. Client

Navigate to the `client` directory and install dependencies if you haven't already:

```bash
cd client
npm install
```

To start the frontend development server:

```bash
npm run dev
```

The client will be available at `http://localhost:3000`.

## Running the Project

To run the full application, you need to have both the backend and client servers running simultaneously in separate terminal windows.
